# Simulation d'attaque par éclipse sur wallet SPV (réseau mobile 3G/4G)

Projet final - Blockchain et Technologies Distribuées - M1 RIST - UFHB
Deadline : 08 août 2026

## Structure du projet

- `scratch/` : scripts principaux NS-3 (points d'entrée des simulations)
- `src/blockchain/` : module blockchain custom (wallet SPV, nœuds honnêtes, attaquant)
- `scenarios/` : scripts pour les 4 scénarios comparatifs (filaire, mobilité modérée/élevée, dégradation signal)
- `results/raw/` : données brutes issues des simulations
- `results/graphs/` : graphiques générés (courbes de taux de succès, etc.)
- `analysis/` : scripts Python d'analyse et de génération des métriques
- `docs/` : notes, captures, documentation de rendu
